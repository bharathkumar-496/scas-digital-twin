# Room evidence photographs

Drop verified IQAC photographs here as `room-<number>.jpg` (for example `room-303.jpg`, `room-345.jpg`).
When a file exists, the Room Inspector and the Room 303 modal show it and tag it `[SOURCE-DERIVED]`.
Without a file, the app falls back to an illustrative render tagged `[ILLUSTRATIVE]`, so nothing is presented as a photograph that isn't one.
